Frequently Asked Questions

Jo sab log puuchte hain

SwachhSetu kya hai? +
SwachhSetu ek smart waste management platform hai jahan citizens waste-related issues report kar sakte hain, real-time track kar sakte hain, aur municipal authorities fast action le sakti hain.
Kya ye free hai? +
Haan! Citizens ke liye ye 100% free hai. Registration karo, complaint report karo, aur status track karo — koi hidden charges nahi.
Complaint resolve hone mein kitna time lagta hai? +
Average response time 24 hours hai. Urgent cases (jaise overflowing bins near schools/hospitals) ko priority di jaati hai.
Kya main complaint track kar sakta hoon? +
Bilkul! Har complaint submit karne pe ek unique Ticket ID milta hai. Track page pe daalo aur real-time status dekho — Submitted, In Progress, Resolved — sab visible.
Kaunse cities mein available hai? +
Filhaal 50+ cities mein active hai. Naye cities mein expand kar rahe hain — apna city recommend karo contact page se.
